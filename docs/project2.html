Objective

Mission Brief

A computer vision pipeline that gives a DJI Tello drone two ways to be controlled: hand gesture recognition (thumbs up = takeoff, thumbs down = land, open palm = track hand) and autonomous calculator tracking using a custom YOLOv8 model trained from scratch.

A five-state mode machine handles seamless switching between modes — if a gesture is lost, the drone searches for a calculator target and vice versa, avoiding dead stops mid-flight. Includes a full debug mode with a laptop webcam so it can be developed without a drone.

Architecture

Mode State Machine

GESTURE — lost gesture → SEARCH CALCULATOR — found calc → CALCULATOR

Nothing found after timeout → SEARCH BOTH → reconnects to the first target seen.

BOSS FIGHT — CRITICAL CHALLENGE

Training a Detector From Zero Data

There was no off-the-shelf "calculator detector" — every image in the dataset had to be collected and labelled from scratch before YOLOv8n could be trained on it. Getting a model accurate enough to track reliably in real time, then tuning the PD-style controller so the drone didn't overshoot or jitter around the target, took the most iteration of the whole project.

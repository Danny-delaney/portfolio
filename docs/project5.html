Objective

What Is It?

A local arena brawler where stone-age fighters square off using clubs, spears and sheer bad temper. The team brainstormed the concept together, then built out a roster of opponents each with their own attack pattern.

Under the hood, every opponent is a polymorphic class — enemies are dynamically assigned to a shared array of base-class pointers, so new fighter types can be added without touching the game loop that drives them.

BOSS FIGHT — BIGGEST CHALLENGE

Wrangling Pointers to an Array of Enemies

Every opponent on screen lived behind a base-class pointer in a shared array, so the game loop could treat a dozen different fighter types identically — call one function, let polymorphism route it to the right attack. The hard part was keeping those pointers honest: making sure a defeated enemy was cleaned up properly instead of leaving a dangling pointer behind, and that the array never got indexed out of bounds while fighters were being added and removed mid-match. Getting that memory management right, under an event deadline with three people touching the same code, was the real fight.

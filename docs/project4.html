Objective

What Is It?

A self-hosted Proxmox server that runs my own infrastructure instead of renting someone else's — currently hosting my personal website, a fully playable online version of my capstone project, and a private, self-hosted messaging service.

Cloudflare Tunnels act as the middleman, exposing these services to the internet securely without opening a single port on my home network, while an end-to-end encrypted messaging layer keeps conversations private even from the server itself.

⚠ Boss Fight

Getting a Real-Time Game Server Onto a Home Connection

Cloudflare Tunnels are built for web traffic, not a custom TCP game protocol expecting a persistent, low-latency connection. Getting the platformer's networking layer to run reliably behind a tunnel — without the port-forwarding a home network normally needs, and without introducing lag that would break the gameplay — took the most reconfiguration of any part of the stack.
